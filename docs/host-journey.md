# Host Customer Journey

## Objective

Turn an independent property owner from curious visitor into an activated host with one verified property, an understandable score, a published profile, and a useful guest guide.

## Journey

### 1. Acquisition

Entry points:

- main AllTheRooms website
- destination travel articles
- host referral
- local provider or association
- property-score landing page

Promise: **Know how your property compares. Give guests everything they need. Turn local knowledge into a better stay.**

Primary action: **Add my property for free.**

### 2. Import

The host pastes an Airbnb, Vrbo, Booking.com, or direct-listing URL.

The product creates a private draft using information that may be lawfully accessed and presents source and freshness details. The host can also enter information manually.

### 3. Registration and claim

The host creates an account after seeing enough preliminary value to continue. Property ownership or management authority is verified before publication or sensitive insights are enabled.

### 4. Confirm property

The host reviews:

- name, address, neighborhood, and coordinates
- capacity, bedrooms, bathrooms, and amenities
- photos and description
- source listings
- primary booking path
- direct contact preference
- team members

Nothing is published automatically.

### 5. Preliminary score

The score explains six components:

1. listing quality
2. value
3. trust and completeness
4. market position
5. guest experience readiness
6. local connection

Each component includes evidence, confidence, limitations, and recommended actions.

### 6. First activation

The host completes three high-value tasks:

- chooses a public booking/contact path
- publishes or previews the property profile
- adds the first five guest-guide items

Activation event: **verified property + published profile + shareable guide.**

### 7. Local network

The property market determines access to:

- verified host community
- local operational providers
- local-business profiles and offers
- destination content and reusable recommendations

### 8. Repeat usage

The host returns for:

- property and market alerts
- guest-guide updates
- service-provider needs
- community questions
- upcoming-stay preparation
- performance and engagement review

## Primary host success metrics

- listing URL submission rate
- import-to-registration conversion
- property claim completion
- time to preliminary score
- profile publication rate
- guest-guide publication rate
- QR creation rate
- 30-day host retention
- provider contact rate
- community contribution rate
- guide engagement per stay

## Failure states to design

- listing URL cannot be imported
- host manages a property but does not own it
- duplicate property already exists
- imported data is stale or inaccurate
- property is outside an active market
- score confidence is low
- host wants a private profile
- source listing is removed
- multiple team members claim the same property
