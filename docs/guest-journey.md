# Guest Customer Journey

## Principle

A guest should receive value without creating an account or downloading an app.

## Discovery journey

```text
Search or referral
→ destination article
→ destination hub
→ relevant property profile
→ Airbnb, Vrbo, direct website, or secure host inquiry
```

Travel content establishes destination expertise and directs guests toward property pages without disguising advertising as editorial recommendation.

## Confirmed-stay journey

```text
Reservation confirmed
→ host sends guest-guide link
→ guest opens public welcome layer
→ reservation access unlocks arrival and house details
→ guest uses local recommendations and offers
→ checkout guidance
→ feedback and repeat-stay path
```

## Guest guide structure

1. Welcome
2. Arrival and parking
3. House information
4. Wi-Fi and equipment
5. Host recommendations
6. Restaurants, shops, and activities
7. Local offers
8. Transportation
9. Emergency resources
10. Checkout
11. Contact host
12. Stay again

## Access levels

| Information | Access |
|---|---|
| Property summary and public recommendations | Public |
| General guide and local offers | Shareable link |
| Parking specifics and arrival window | Confirmed guest |
| Door, gate, or alarm credentials | Expiring reservation access |
| Guest identity and messages | Host team and guest only |

A printed permanent QR code can open the property guide, but it must never expose permanent door codes or guest-identifying information.

## Local offer journey

A guest can view, save, call, request directions, book externally, or redeem an offer. Sponsored placements are labeled. Host recommendations remain distinct from advertisements.

## Guest success metrics

- guide delivery and open rate
- time to find arrival information
- host-contact deflection for repeated questions
- local recommendation engagement
- offer redemption
- checkout completion
- post-stay satisfaction
- repeat-contact or booking intent

## Design requirements

- mobile first
- no required download
- fast on weak connections
- accessible type and controls
- English and Spanish support
- offline-safe essential house information where authorized
- clear emergency separation
- privacy-respecting analytics
